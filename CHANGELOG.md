# Changelog

## 0.4.0

- Rounded standalone application launcher and dashboard popups.
- Reference rounded and Fluent-inspired styles with desktop/light/dark modes.
- Optional KWin blur and contrast-aware calendar controls.
- Reversible slim left rail and floating bottom bar presets with native popup launch buttons.
- Layout/look changes can preserve the KDE palette; popup preferences and panel launchers participate in rollback.
- Native KDE application launching; search is data only.


## 0.3.0

- Local wallpaper selection and matching KDE color palettes.
- Reversible additions of installed, allowlisted Plasma desktop widgets.
- Native desktop dashboard, KRunner launcher and MPRIS controls.
- About and optional GitHub release monitoring.
- Correct accent serialization and extend rollback to wallpaper/widgets.

## 0.2.0

- Add 22 official Omarchy palettes, including Osaka Jade.
- Validate generated KDE RGB color values.

## 0.1.0

- Native KDE appearance trials, panel adjustment, profiles and session handoff.
- Input-aware Yes/No confirmation and independent recovery worker.
