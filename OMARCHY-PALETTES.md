Official Omarchy palette data, adapted to KDE color roles.

Source: https://github.com/omacom/omarchy/tree/dccd88b6c97f3b7b8ae6168bd110a872237bf673/themes

License: see OMARCHY-LICENSE. The development snapshot also includes one associated wallpaper from each of the 22 theme background folders, selected from the same source commit and retained with the upstream license. No Omarchy scripts, executables or session configuration are included. These are KDE palette equivalents; application-specific Omarchy styling is not applied.

For Last Horizon, Solitude and White, the neutral/warning role uses the supplied yellow because upstream provides no orange.
