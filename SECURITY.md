# Security

KamaKiriStudio never runs commands from imported profiles or downloads/installs updates automatically. Only allowlisted installed KDE widgets can be added. Wallpaper formats and decoded sizes are bounded. Every appearance trial has a private snapshot and an independent recovery worker.

If you discover a vulnerability, use GitHub private vulnerability reporting if enabled; avoid posting credentials or private desktop files in public issues. A code review and these checks cannot guarantee absence of vulnerabilities.
